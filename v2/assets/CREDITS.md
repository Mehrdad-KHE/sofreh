# Demo assets

Eight menu JPGs are unmodified downloaded files from Wikimedia Commons; an earlier Ghormeh candidate is retained unused. The interface uses CSS object-fit cropping. Food photographs are samples and do not represent the fictional cooks' own products. Original kitchen SVG logos were created for this demo; no third-party brand artwork is used.
